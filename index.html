How to use

  1. The limit file loads automatically from GitHub. Pick another version, or load your own limit CSV, from the Limits list.
  2. Drag the test data CSV onto the drop box, or click it to browse. A pass/fail summary for the last run appears on the left.
  3. Pick a segment and test, then click Show to see the data tables and plots. Click any cell in the summary to jump to that test.
  4. To save the report, click Print report and pick "Save as PDF".

Want to see how it works first? Download the sample data (made-up values), or click Try the sample on the left.

Everything runs in your browser. The data file is never uploaded anywhere. After the first visit the app also works offline, and you can install it with Install app (Chrome/Edge) or "Add to Home Screen" (phones).
